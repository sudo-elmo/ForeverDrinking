# Forever Drinking

Shows on the default Blizzard raid and party frames when someone is **drinking** – for **World of Warcraft: Forever**.

Healers and casters no longer have to ask "are you drinking?": a drink icon and/or a "Drinking" label appears right on the player's frame as long as they sit and drink.

---

## Features

- Works on the Blizzard raid frames (and raid-style party frames) and on the classic party frames with portraits
- Show as icon, text or both
- Own look for raid frames and party frames: position on the frame (e.g. centred in the mana bar), offset, icon size, text size, outline and colour
- Optional blinking so it stands out more
- Preview on all frames to set it up (solo: open Edit Mode and tick "Party Frames")
- English and German (follows your game language)

## Commands

| Command | |
|---|---|
| `/fdrink` or `/trinken` | Open the settings |

Settings are also under Options → AddOns → Forever Drinking.

## Install

Download the zip from the [latest release](../../releases/latest) and unpack it into `World of Warcraft/_forever_/Interface/AddOns/`.
